# Laboratory 01 - Welcome to the Cloud

## Mission Overview

This laboratory activity is about learning the basic skills needed in cloud computing. It includes using Linux, organizing files, using GitHub, and documenting technical work.

## Objectives

- Access a cloud-based Linux environment.
- Explore and navigate Linux.
- Gather system information.
- Organize files and directories.
- Create a GitHub repository.
- Use Markdown documentation.

## Activities Performed

- Accessed Ubuntu using KillerCoda.
- Created and used a Linux user.
- Checked system information.
- Created folders and Markdown files.
- Created a GitHub repository.
- Prepared documentation.

## Linux Commands Used

- whoami
- pwd
- hostname
- useradd
- passwd
- su
- cat
- uname
- lscpu
- free
- df
- mkdir
- nano
- ls

## Skills Learned

I learned how to use basic Linux commands, create and organize files, gather system information, and use GitHub for documentation.
