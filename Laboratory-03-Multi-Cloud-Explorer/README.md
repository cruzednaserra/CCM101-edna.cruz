# Laboratory 03 - Multi-Cloud Explorer

## Mission Overview

In this laboratory, I explored the three major cloud platforms which are Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). I learned about their services, infrastructure, advantages, and common uses.

I also used Linux commands in KillerCoda to check the operating system, CPU, memory, and disk space. The goal of this activity is to understand how cloud providers can be selected based on the needs of a business.

## Linux Investigation

### Operating System

The Linux environment used Ubuntu.

### CPU Information

I used the `lscpu` command to check the CPU information.

### Memory

I used the `free -h` command to check the memory.

### Disk Space

I used the `df -h` command to check the available disk space.

## If the Linux Server is Migrated to Cloud

| Cloud Provider | Service |
|---|---|
| AWS | Amazon EC2 |
| Microsoft Azure | Azure Virtual Machines |
| Google Cloud | Compute Engine |

These services can be used to run Linux virtual machines in the cloud.
