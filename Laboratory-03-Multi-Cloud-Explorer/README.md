# Linux Investigation

## Operating System

The Linux server is running Ubuntu.
I checked the operating system using:
```bash
cat /etc/os-release
```
## CPU Information
I used the following command:
```bash
lscpu
```
The command showed the CPU information of the Linux server.
## Memory
I used:
```bash
free -h
```
This command showed the total and available memory of the server.
## Disk Space
I used:
```bash
df -h
```
This command showed the used and available disk space.
