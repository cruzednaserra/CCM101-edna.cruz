# Google Cloud Platform Research

## Brief Overview
Google Cloud Platform (GCP) is Google's cloud computing platform. It provides services for computing, storage, databases, networking, Artificial Intelligence, data analytics, and Kubernetes.

## Global Infrastructure
Google Cloud uses Regions and Zones around the world. Its cloud infrastructure is designed to provide reliable access to cloud resources in different locations. (Google Cloud, n.d.)

## Cloud Management Console
The Google Cloud Console is a web-based interface used to manage Google Cloud projects and resources. Users can create, configure, and monitor cloud services using the console.

## Four Core Services

### 1. Compute Engine
Compute Engine provides virtual machines for running applications.

### 2. Cloud Storage
Cloud Storage is an object storage service used to store files and other data.

### 3. Cloud SQL
Cloud SQL is a managed relational database service.

### 4. Google Kubernetes Engine
Google Kubernetes Engine (GKE) is a managed Kubernetes service used to run containerized applications. (Google Cloud, n.d.)

## Three Advantages
1. Strong support for Artificial Intelligence and Machine Learning.
2. Strong data analytics services.
3. Strong Kubernetes support.

## Typical Enterprise Use Cases
GCP can be used for Artificial Intelligence, Machine Learning, data analytics, web applications, databases, and container applications.
