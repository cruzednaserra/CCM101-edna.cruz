# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform or GCP is Google's cloud platform. It provides services for computing, storage, databases, networking, artificial intelligence, data analytics, and Kubernetes.

## Global Infrastructure

Google Cloud has regions and zones around the world. It also uses Google's global network to connect its cloud infrastructure.

## Cloud Management Console

The Google Cloud Console is a web interface used to manage Google Cloud resources and projects. It also provides access to Cloud Shell and different Google Cloud services.

## Four Core Services

1. Compute Engine - used for virtual machines.
2. Cloud Storage - used for object storage.
3. Cloud SQL - used for relational databases.
4. Google Kubernetes Engine (GKE) - used for Kubernetes workloads.

## Three Advantages

1. Strong in artificial intelligence and machine learning.
2. Strong in data analytics.
3. Strong support for Kubernetes.

## Typical Enterprise Use Cases

GCP can be used for AI and machine learning, big data, analytics, web applications, container applications, and cloud databases.
