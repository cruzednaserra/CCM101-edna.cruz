# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud platform from Microsoft. It is used for building, deploying, and managing applications and cloud services. Azure was launched in 2010.

## Global Infrastructure

Azure has many regions around the world. An Azure region contains one or more datacenters connected by a high-capacity network. Azure also has availability zones and paired regions for some locations.

## Cloud Management Console

The Azure Portal is the web-based management interface of Azure. It can be used to create, configure, monitor, and manage Azure resources.

## Four Core Services

1. Azure Virtual Machines - used for virtual servers.
2. Azure Blob Storage - used for object storage.
3. Azure SQL Database - used for SQL databases.
4. Microsoft Entra ID - used for identity and access management.

## Three Advantages

1. Strong integration with Microsoft products.
2. Good support for hybrid cloud environments.
3. Provides many services for enterprise organizations.

## Typical Enterprise Use Cases

Azure can be used for Windows Server workloads, Microsoft 365 environments, databases, web applications, virtual machines, and hybrid cloud systems.
