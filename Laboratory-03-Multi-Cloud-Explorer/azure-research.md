# Microsoft Azure Research

## Brief Overview
Microsoft Azure is a cloud computing platform created by Microsoft. It provides services for computing, storage, databases, networking, security, and application development. Azure was launched in 2010. (Microsoft, n.d.)

## Global Infrastructure
Azure has Regions around the world. It also provides Availability Zones in supported regions. Availability Zones are physically separate locations inside an Azure Region and help protect applications from local failures. (Microsoft, n.d.)
Azure also uses Region Pairs in its global infrastructure to support reliability and disaster recovery.

## Cloud Management Console
The Azure Portal is the web-based management tool for Microsoft Azure. It allows users to create, configure, monitor, and manage Azure resources.

## Four Core Services

### 1. Azure Virtual Machines
Azure Virtual Machines are used to run virtual servers in the cloud.

### 2. Azure Blob Storage
Azure Blob Storage is used to store files and other unstructured data.

### 3. Azure SQL Database
Azure SQL Database is a managed SQL database service.

### 4. Microsoft Entra ID
Microsoft Entra ID is Microsoft's cloud identity and access management service. It was previously called Azure Active Directory. (Microsoft, n.d.)

## Three Advantages
1. Strong integration with Microsoft products.
2. Good support for hybrid cloud environments.
3. Many services are designed for enterprise organizations.

## Typical Enterprise Use Cases
Azure can be used for Windows Server workloads, databases, virtual machines, Microsoft applications, web applications, and hybrid cloud systems.
