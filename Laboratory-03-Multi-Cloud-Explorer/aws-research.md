# AWS Research

## Brief Overview

Amazon Web Services or AWS is a cloud platform from Amazon. It provides many cloud services for computing, storage, databases, networking, security, and other needs. AWS was launched in 2006. 

## Global Infrastructure

AWS has a global infrastructure made of Regions and Availability Zones. A Region is a geographic area and Availability Zones are separate locations inside a Region. These help applications have better availability.

## Cloud Management Console

The AWS Management Console is a web interface used to access and manage AWS services. Users can manage resources, users, billing, and services using the console.

## Four Core Services

1. Amazon EC2 - used for virtual servers.
2. Amazon S3 - used for object storage.
3. Amazon RDS - used for managed relational databases.
4. AWS IAM - used to manage users and permissions.

## Three Advantages

1. AWS has many cloud services.
2. It can scale resources when needed.
3. It supports many types of businesses and workloads.

## Typical Enterprise Use Cases

AWS can be used for web applications, databases, backups, data processing, storage, and enterprise applications.
