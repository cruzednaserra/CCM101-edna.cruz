# AWS Research

## Brief Overview
Amazon Web Services (AWS) is a cloud computing platform from Amazon. It provides cloud services for computing, storage, databases, networking, security, and other IT needs. AWS was launched in 2006. (Amazon Web Services, n.d.)

## Global Infrastructure
AWS uses Regions and Availability Zones. A Region is a geographic area where AWS provides cloud services. Availability Zones are separate locations inside a Region. They help improve availability and fault tolerance. (Amazon Web Services, n.d.)

## Cloud Management Console
The AWS Management Console is a web-based interface used to access and manage AWS services. Users can create, configure, monitor, and manage cloud resources using the console. (Amazon Web Services, n.d.)

## Four Core Services
### 1. Amazon EC2
Amazon EC2 provides virtual servers that can be used to run applications.

### 2. Amazon S3
Amazon S3 is an object storage service used for files, backups, images, videos, and other data.

### 3. Amazon RDS
Amazon RDS is a managed relational database service.

### 4. AWS IAM
AWS IAM is used to manage users, roles, and permissions in AWS.

## Three Advantages
1. AWS has a wide range of cloud services.
2. Resources can be increased or decreased when needed.
3. AWS can be used by startups, enterprises, and other organizations.

## Typical Enterprise Use Cases
AWS can be used for web applications, databases, file storage, backups, enterprise applications, and large-scale systems.
