# Mission 3 Reflection

The cloud platform that impressed me the most is Microsoft Azure. I choose Azure because it has many services and it works very good with Microsoft products. Since many organizations use Windows Server, Microsoft 365, and Active Directory, Azure can be useful for enterprise environments.

AWS, Azure, and Google Cloud have many similarities. All three provide virtual machines, storage, databases, networking, identity management, and other cloud services. They also use regions and different infrastructure locations to provide better availability. The names of the services are different but they can perform similar jobs.

Business requirements are important when selecting a cloud provider. A company should not choose a provider only because it is popular. They need to look at their budget, applications, existing systems, security needs, location of users, and future growth. For example, a company using many Microsoft products may benefit more from Azure, while an AI company may choose Google Cloud.

Acting as a Cloud Solutions Consultant helped me understand that cloud computing is not only about knowing the services. I also need to understand the problem of the client first before choosing a solution. I learned how to compare different cloud platforms and match their services to a business requirement.

My GitHub Cloud Computing Portfolio also improved after this activity. I learned how to organize my research and documentation using Markdown. I also learned that keeping screenshots and files organized can make my work easier to check and understand.
